Visual Standards

Operational Protocol for Multimedia Crew
01

Typography & Scale

Legibility from the back row of the sanctuary is paramount. Never crowd slides with excess characters.

Headings / Song Titles: 48pt – 54pt (Bold weights required).

Body / Lyrics / Verses: 60pt – 72pt. Limit enough lines to avoid exceeding screen width.

Fonts: Bebas Neue for overall display.

Cue Styling: Red for instrumentals, Light Green for Highlights and Repetitions.

02

Approved Color System

Maintain high contrast colors for consistent usage of prompter palettes.

Background #0C0C10
Lyrics #FFFFFF
Structures #FFCD00
Instrumental #FB2943
Repetition #CCFFCC
03

Live Service Execution

Contrast Rule: Ensure crisp white or gold text over dark backgrounds. Avoid mid-tone gray-on-gray palettes.

Visual Margins: Keep text well clear of display borders. Maintain a safe padding zone around all slide elements.

Background Control: Use clean, distraction-free gradients or approved motion loops that support rather than obscure the text content.

Visuals Inspector Panel

How to Change Background Color

Modify the background color of slides or presentation templates directly inside ProPresenter 7:

  • Select the target slide or presentation cue in your arrangement tray.
  • Open the Inspector Panel on the right side of the main workspace.
  • Go to the Slide Properties tab and click on the Fill color block.
  • Choose a solid color fill, radial gradient, or clear backdrop value to apply your custom stage tint.
Workflow File > Import

How to Import a Song via Clipboard

Quickly pull in lyrics copied from external text sources, ChordPro sheets, or web browsers:

  • Copy your formatted song lyrics (with verses and choruses labeled clearly) to your system clipboard.
  • In Pro7, navigate to top menu File > Import > Song from Clipboard.
  • Review stanza breaks and group tagging in the quick-import preview modal.
  • Assign the correct CCLI song number, select your library folder, and confirm import.
Workflow .proBundle

How to Import a Pro7 Bundle

Restore or unpack complete service packages containing media, templates, and libraries:

  • Double-click the .proBundle file directly, or open Pro7 and go to File > Import > Bundle.
  • Select your bundle package archive from your local directory.
  • Choose your active library destination folder for the unpacked presentation documents.
  • Verify that all embedded video loops and audio stems link correctly in your repository.
Visuals Media Bin

How to Import Background & Media

Ensure smooth video loop playback during live services without broken links or stuttering frames:

  • Store all source loop files in a dedicated local media repository folder before linking.
  • Drag and drop your video files directly into the Pro7 Media Bin tray.
  • Right-click the media item, open properties, and ensure playback behavior is set to Loop.
  • Avoid playing media directly off removable USB thumb drives during active worship services.
Workflow Right-Click > Export

How to Bundle in Pro7

Export a presentation package along with all integrated media, audio, and custom templates:

  • Right-click your active service playlist or individual presentation file in the library.
  • Select Export > Bundle... from the context menu.
  • Check the options to include media assets, audio tracks, and custom theme designs.
  • Save the package archive to your local backup drive or cloud sync folder.
Workflow Ctrl / Cmd + N

How to Create a New Presentation

Start a clean project deck from scratch for custom announcements or sermon slides:

  • Click the + (New Presentation) icon in the library toolbar or press Cmd/Ctrl + N.
  • Name your presentation file clearly (e.g., Sunday Worship - Date).
  • Confirm your target aspect ratio (Standard 16:9 widescreen) and select the active library folder.
  • Click New Presentation to open the empty slide editing grid.
Compliance Final Slide

How to Create Credits

Properly attribute media and song copyright data according to ministry standards:

  • COGW (COG Worship / Licensed Content): Include the year of publication, along with the title of the song.
  • Non-COGW / External Sources: Clearly credit the song title along with the band/church name only. Exclude the year of publication.
Editor Transition Inspector

How to Create Transitions

Add smooth visual motion between slides or background media cues:

  • Open the Cue Properties or presentation build settings menu.
  • Select your preferred slide transition effect (e.g., Dissolve, Push, or Cut).
  • Adjust the transition duration slider (recommended: 0.5s to 1.0s for smooth worship flow).
  • Apply the transition globally to your song arrangement or individually to specific title slides.
Editor Build Order

How to Build with Transitions

Animate individual text elements and objects arriving on a single slide sequentially:

  • Open your slide inside the ProPresenter Editor workspace.
  • Select the specific text box, scripture block, or graphic element you want to animate.
  • Configure its build-in transition properties (Fade In, Fly In) in the right-hand inspector.
  • Use the build order timeline to stagger multiple text lines so they trigger step-by-step during live presentation.
Visuals Scaling Mode

How to Media Fill

Adjust how background loops and images fit across different screen display ratios without awkward letterboxing:

  • Select the media fill property on your background cue or screen layer in Pro7.
  • Choose Fill to scale and crop the video to completely cover the screen without black borders.
  • Choose Fit if you need the entire image visible without any edge cropping.
  • Fine-tune alignment scaling parameters if your stage utilizes custom LED wall dimensions.
Editor Typography Panel

How to Change Spacing & Letter Space

Refine line spacing and character kerning for optimal readability on sanctuary projection displays:

  • Open your text box inside the ProPresenter Editor and highlight your text content.
  • Locate the typography metrics panel in the right-hand inspector menu.
  • Adjust Line Spacing to prevent overlapping lyric lines on multi-line projection slides.
  • Modify Letter Spacing (Tracking) to widen display headings or tighten bold display text cleanly.
